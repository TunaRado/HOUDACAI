# Houdacai Website

## Coming Soon Page

This is a simple coming soon page for Houdacai.com featuring:
- Company logo prominently displayed
- "Things coming soon..." message
- Responsive design that works on all devices
- Beautiful gradient background
- Animated dots for visual appeal

## Files

- `index.html` - Main coming soon page
- `houdacai_logo.svg` - Company logo

## To Deploy

1. Upload all files to your web hosting provider
2. Point your domain (houdacai.com) to the hosting directory
3. The `index.html` will automatically load as the homepage
